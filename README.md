# PentoGraf 1024K - A Pentagon 1024K Clone

This repository documents the complete development of a functional Pentagon 1024K Clone, following the schematics, 
layout, and design principles.

The project is organized into multiple hardware-specific
sub-repositories. Each one contains schematics, PCB layouts,
documentation, and photos related to a specific module of the system.

The goal is to faithfully reproduce a Pentagon 1024K Clone
architecture while documenting the full hardware development process.

1) Harlequin 128K Motherboard, Keyboard and Case: https://github.com/frubem/PentoGraf-Pentagon-1024k 
2) ZX-MultiIO: https://github.com/frubem/ZX-MultiIO
3) DivMMC Nemo: https://github.com/frubem/DivMMC-Nemo
3) IDE Nemo: https://github.com/frubem/IDE-NEMO
4) ZX BUS Mouse: https://github.com/frubem/ZX_BUS_Mouse
5) ZX Multisound: https://github.com/frubem/zx-multisound
